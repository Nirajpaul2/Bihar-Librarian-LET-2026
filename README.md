# Bihar Librarian LET 2026

Professional preparation platform for the **Bihar Librarian Eligibility Test (LET) 2026** conducted by the **Bihar School Examination Board (BSEB)**.

---

## 📖 Overview

The platform is designed to take students from study to practice, mock testing, and performance review:

* **Part 1: Library & Information Science (100 Marks / 66.6%)** — Technical core covering Classification (DDC, Colon Classification), Cataloguing (AACR-2, CCC), Library Management, Reference Services, and Digital Automation (KOHA, SOUL, e-Granthalaya, NDLI, INFLIBNET).
* **Part 2: General Paper (50 Marks / 33.4%)** — Non-technical paper covering Bihar State GK, Indian General Knowledge, Reasoning & Analytical Ability, and Basic Computer Awareness.
* **Exam Framework**: 150 Questions · 150 Marks · 120 Minutes · No Negative Marking · Online CBT Mode.

---

## ⚡ Key Features

* **Freemium Access Model**:
  * **Unit 1 (Foundations of Library Science)** is **100% FREE** for all students.
  * Razorpay integration (₹9 one-time lifetime access) to unlock Units 2–6, General Paper, and Full 150Q Mock Tests.
* **Interactive 4-Tab Syllabus Explorer**:
  * 📋 *Exam Overview* — Blueprint and exam rules.
  * ⚖️ *Topic-Wise Weightage Analysis* — Tier 1 (45%), Tier 2 (35%), Tier 3 (20%) breakdown.
  * 📖 *Full Syllabus Tree* — Expandable subjects, units, and topics with direct practice links.
  * 📅 *30-Day Daily Study Plan* — Phase-wise schedule dividing daily study between Technical Core (3.5h) and General Paper (1.5h).
  * ⚡ *Quick Revision Cheat Sheets* — Master Table of Indian Public Library Acts (19 states + Bihar 2008), DDC 10 Main Classes (000–900), Colon Classification PMEST connecting symbols, and Dr. S. R. Ranganathan Five Laws.
* **Practice Hub**:
  * Topic-wise, unit-wise, and subject-wise MCQ practice.
  * Immediate answer evaluation with educational explanations.
  * Daily 10-Question challenge & quick random practice.
* **Full-Length Mock Test Simulator**:
  * Timed exam environment with countdown timer.
  * Question navigator, review flag, and instant performance analysis.
* **Dark Mode & Bookmarking**:
  * Dark/Light theme toggle.
  * LocalStorage-backed bookmarking for reviewing challenging questions.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+ recommended)
* npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Nirajpaul2/Bihar-Librarian-LET-2026.git
cd Bihar-Librarian-LET-2026

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
